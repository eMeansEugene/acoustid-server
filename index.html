AcoustID — Audio Fingerprinting Server

Обзор

AcoustID Server — серверное приложение на C++20, реализующее акустическую идентификацию аудио по принципу Shazam. Сервис принимает короткий аудиофрагмент (5–15 секунд), строит его цифровой отпечаток на основе FFT и constellation map, ищет совпадение в заранее подготовленной базе хэшей и возвращает трек, временну́ю позицию совпадения и степень уверенности.

База данных наполняется офлайн — через CLI-инструмент indexer или защищённый административный HTTP-эндпоинт. Конечный пользователь взаимодействует только с операцией распознавания (POST /match), которая обрабатывается асинхронно: HTTP-поток не блокируется на время вычислений — их выполняет пул рабочих потоков (WorkerPool).

Архитектура слоистая: Server → Domain → Core + Storage. Слои взаимодействуют только через абстрактные интерфейсы, что позволяет, например, заменить SQLite на другую БД без изменения бизнес-логики. Подробности — на странице Архитектура.

Как собрать проект, поднять сервер, проиндексировать треки и отправить первый запрос на распознавание — см. Быстрый старт.

Модули

  • Модуль core — вычислительное ядро: FFT, пики, хэши, голосование
  • Модуль audio — декодирование MP3/WAV в сэмплы
  • Модуль domain — бизнес-логика: индексирование и распознавание
  • Модуль storage — хранилище треков и fingerprints (SQLite)
  • Модуль server — HTTP-сервер, очередь задач, пул воркеров

Архитектура

Слоистая архитектура, поток данных при индексировании и распознавании, алгоритмы (спектрограмма, constellation map, хэши, голосование), частотные полосы — см. Архитектура.
