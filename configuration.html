Оба исполняемых файла (acoustid_server, indexer) читают JSON-конфиг (AppConfig::LoadFromFile, по умолчанию config.json, путь задаётся --config). Отсутствующие поля и секции сохраняют значения по умолчанию (AppConfig::Defaults()) — конфиг можно указывать частично. Если файл целиком отсутствует или не парсится — используются только значения по умолчанию, сервер не падает. Пример полного конфига — configs/default_config.json.

server

Поле Тип По умолчанию Влияет на
port int 8080 TCP-порт, на котором HttpServer::Run() поднимает Crow.
api_key string "changeme" Значение заголовка X-Api-Key, требуемое для POST /admin/index. Обязательно смените в проде.
workers int 4 Читается из конфига, но в текущей версии не применяется — main_server.cpp всегда создаёт WorkerPool с 4 потоками (num_workers захардкожен в main()). Меняя это поле, число реальных воркеров не изменится.
max_upload_bytes int 50 МБ (52428800) Максимальный размер тела запроса POST /match и POST /admin/index; превышение — 413.
debug_save_audio bool false Если true, каждый входящий на /match файл сохраняется в debug_audio_dir под именем {task_id}.wav — удобно для сбора реальных записей на тестирование (см. Тестирование).
debug_audio_dir string "debug_audio" Каталог для файлов, включённых предыдущим полем. Создаётся сервером при необходимости.

database

Поле Тип По умолчанию Влияет на
path string "tracks.db" Путь к файлу SQLite (SQLiteRepository). ":memory:" создаёт временную БД в памяти — используется в тестах.

fft

Параметры FftEngine (см. Спектрограмма в Архитектура).

Поле Тип По умолчанию Влияет на
frame_size int 2048 Размер окна FFT в сэмплах. Больше — точнее по частоте, хуже по времени (и наоборот). Должен быть чётным.
hop_size int 1024 Шаг между соседними фреймами. hop_size = frame_size / 2 — перекрытие 50%. Меньший шаг даёт больше фреймов (плотнее по времени, дороже вычислительно).
Warning
frame_size и hop_size должны совпадать между индексированием и распознаванием — иначе структура fingerprints будет несопоставима. Меняя эти параметры, нужно переиндексировать всю базу.

peak_extractor

Параметры PeakExtractor (см. Constellation map и Частотные полосы в Архитектура).

Поле Тип По умолчанию Влияет на
frame_radius int 2 Радиус окна проверки локального максимума по времени: полное окно 2·N+1 фреймов.
bin_radius int 2 Радиус окна проверки локального максимума по частоте: полное окно 2·N+1 бинов.
offset_db float 6.0 Отступ порога отбора пика от медианы мощности фрейма, дБ. Меньше — больше пиков (и шума), больше — меньше пиков.
zone_frames int 43 (~1 сек при hop_size=1024, sr=44100) Размер временно́й зоны для контроля плотности пиков.
peaks_per_band int 4 Максимум пиков на одну частотную полосу (см. Частотные полосы) в одной зоне. Больше — плотнее constellation map (точнее, но дороже по хранению и поиску).

hash_generator

Параметры HashGenerator (см. Хэши и 32-битный хэш в Архитектура).

Поле Тип По умолчанию Влияет на
max_target_offset int 100 Максимальное расстояние (во фреймах) от пика-якоря до пика-цели при построении пар.
max_targets_per_anchor int 3 Сколько целей берётся на один якорь (ближайшие по времени). Больше — больше хэшей на трек (плотнее база, дольше индексирование).
freq_bin_limit int 512 Верхняя граница bin_index, участвующего в хэшах (9 бит на частоту — максимум 512). Пики выше отбрасываются.

voting

Параметры VotingEngine (см. Голосование (two-level: track → delta) в Архитектура).

Поле Тип По умолчанию Влияет на
min_votes int 10 Минимальное абсолютное число голосов для победителя. Ниже — nullopt (нет совпадения), даже если он единственный кандидат.
min_score_ratio float 2.0 Минимальное отношение голосов победителя к второму месту (+∞, если конкурентов нет). Выше — строже фильтрация случайных совпадений, но и выше риск ложноотрицательного результата на зашумлённых фрагментах.

Как менять параметры осмысленно

  • Понизить offset_db и/или увеличить peaks_per_band — если распознавание часто выдаёт "no match" на реальных, не идеальных записях с микрофона (больше пиков — больше шансов набрать min_votes).
  • Повысить min_score_ratio — если система путает похожие треки (навязчивая ложноположительная идентификация).
  • Изменение frame_size, hop_size, max_target_offset, max_targets_per_anchor или freq_bin_limit меняет формат fingerprints — требует переиндексирования всей базы.
