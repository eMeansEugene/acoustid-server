@mainpage AcoustID — Audio Fingerprinting Server

@section intro Обзор

AcoustID Server — серверное приложение на C++20, реализующее акустическую
идентификацию аудио по принципу Shazam. Сервис принимает короткий
аудиофрагмент (5–15 секунд), строит его цифровой отпечаток на основе FFT и
constellation map, ищет совпадение в заранее подготовленной базе хэшей и
возвращает трек, временну́ю позицию совпадения и степень уверенности.

База данных наполняется офлайн — через CLI-инструмент `indexer` или защищённый
административный HTTP-эндпоинт. Конечный пользователь взаимодействует только с
операцией распознавания (`POST /match`), которая обрабатывается асинхронно:
HTTP-поток не блокируется на время вычислений — их выполняет пул рабочих
потоков (`WorkerPool`).

Архитектура слоистая: `Server → Domain → Core + Storage`. Слои взаимодействуют
только через абстрактные интерфейсы, что позволяет, например, заменить SQLite
на другую БД без изменения бизнес-логики. Подробности — на странице
@subpage architecture.
